ManoMano Orders Importer for Prestashop 1.7
==========================================

Instalación:
1. Subir la carpeta 'manomanoorders' a /modules/ en tu instalación de Prestashop.
2. En el backoffice, ir a Módulos y buscar 'ManoMano Orders Importer' e instalar.
3. En la configuración del módulo, añadir tu API Key (x-api-key) y Seller Contract ID.
4. Ir a 'ManoMano Orders' en el menú para listar pedidos y usar 'Importar a Prestashop'.

Notas importantes:
- Este módulo es una base funcional para importar pedidos. Dependiendo de tu tienda deberás:
  * Ajustar impuestos y reglas fiscales.
  * Mapear correctamente SKUs/ referencias de ManoMano con tus productos.
  * Ajustar transportistas, estados de pedido y métodos de pago.
  * Añadir validaciones y logs para producción.

Soporte:
- Es recomendable probar primero en un entorno de desarrollo antes de usar en producción.
